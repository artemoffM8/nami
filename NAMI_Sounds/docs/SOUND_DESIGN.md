# NAMI — Sound & Music Design Pack (v2)

Обновлённый набор: более тёплые, «живые» звуки + длинный бесшовный ambient для глубокого фокуса.

---

## Структура

```
NAMI_Sounds/
├── sfx/
│   ├── digit_place.wav      ← мягкий бумажно-деревянный клик
│   ├── note_place.wav       ← тихий сухой бумажный tap
│   ├── cell_select.wav      ← очень лёгкий выбор
│   ├── erase.wav            ← мягкое стирание
│   ├── row_complete.wav     ← тёплый стеклянный колокольчик
│   ├── error.wav            ← почти неслышный
│   ├── victory.wav          ← спокойный тёплый джингл ~1.15 с
│   └── ui_confirm.wav       ← подтверждение UI
├── music/
│   └── ambient_focus_loop.wav   ← 48 сек, бесшовный loop для релакса и концентрации
└── docs/
    └── SOUND_DESIGN.md
```

Все файлы: 44.1 kHz, 16-bit PCM, mono.

---

## Что изменилось в v2

**SFX**
- Добавлена мягкая текстура бумаги/дерева (фильтрованный шум)
- Более естественные огибающие
- Тёплые гармоники вместо «сухих» синусов
- Ошибка осталась почти немой

**Музыка**
- Новый трек `ambient_focus_loop.wav` — **48 секунд**
- Специально сделан с 3.5-секундным кроссфейдом на стыке → при зацикливании **нет слышимого перехода**
- Очень медленное «дыхание», низкая плотность, тёплый низ + едва заметный воздух
- Идеален для длительных сессий решения

## Как правильно зациклить музыку в коде

```swift
// AVAudioPlayerNode + seamless loop
player.scheduleBuffer(buffer, at: nil, options: .loops)
```

Поскольку кроссфейд уже вшит в файл, дополнительный fade в коде не нужен — переход будет незаметен.

Аудиосессия: `.ambient` (уважает беззвучный режим и музыку пользователя).
